# Component Discovery, Skill Enhancement & 21st.dev First Rule

## Mandatory Workflow for UI & Frontend Projects
Whenever building, enhancing, or auditing a web application, landing page, or UI interface:

1. **Active 21st.dev Component Discovery from the Start**:
   - Before writing custom UI components from scratch, query the `21st` MCP server (`search`, `search_picker`).
   - Identify top-tier community components (e.g., kinetic text reveals, interactive buttons, bento cards, particle systems, dock navigation, shaders).
   - Retrieve candidate components using `get_component({ id })`, adapt them into the project's design system and framework version (e.g., React 19, Tailwind v4), and blend them with domain logic.

2. **Proactive Skill Evaluation & Expansion (`find-skills`)**:
   - When reviewing the project requirements and visual complexity, assess whether installing specialized agent skills from the open ecosystem (`skills.sh` / `npx skills find`) can materially elevate output quality.
   - Examples of skills to consider when relevant:
     - Advanced 3D & WebGL shaders (Three.js / Canvas)
     - Specialized physics & motion choreographies
     - Comprehensive SEO / structured data auditing
     - End-to-end browser testing and performance profiling
   - If a high-quality skill with proven adoption exists that makes the website noticeably better, proactively install and apply its instructions.

3. **Maximized Visual Impact & Polish**:
   - Leverage both the component catalog and specialized domain skills to ensure maximum aesthetic fidelity, tactile feedback, and smooth micro-interactions.
