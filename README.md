# MOTIONFORM — Modular Creative Video & Motion Platform

> **Governing Principle**: *"Nothing simply appears. Everything transforms."*

An original, browser-based creative motion graphics and video composition platform. Inspired by modern modular creative tools, reusable motion blocks, and high-framerate local GPU rendering.

---

## ✨ Features

- **Cinematic Experience**: 12-section narrative with masked typography, perspective depth, and responsive canvas stage.
- **Interactive Creative-Block Playground**: 4 live configurable primitives (Kinetic Typography, Specular Lumina, Quantum Halftone, 3D Isometric Prism) with real-time sliders and presets.
- **Layered Timeline & Compositing**: Scrubbable playhead, multi-track timeline, independent layer muting, and sub-frame precision.
- **Multi-Modal Creation**: Seamless switching between Remix (templates), Describe (natural language simulation), and Build (atomic assembly).
- **Template Discovery**: Searchable catalog of master video templates across multiple aspect ratios (16:9, 9:16, 1:1).
- **Synchronized Brand Design Tokens**: Centralized colorways and typography scales that re-theme all composition scenes in real time.
- **Local-First Privacy**: Client-side GPU acceleration via WebGL/WebGPU with zero cloud rendering wait times.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev) + TypeScript
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) with CSS Custom Properties
- **Motion**: [Motion](https://motion.dev) / Spring Physics
- **Icons**: [Lucide React](https://lucide.dev)

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/aryankumar-07/notion-studio.git
cd notion-studio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
